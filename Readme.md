# Cozy Cup Cafe

## Project Description
Cozy Cup Cafe is a simple, responsive web application designed for a local coffee shop. The project focuses on creating a warm, inviting digital space where customers can browse specialty coffee drinks and homemade pastries, reflecting the "cozy" atmosphere of a real-world cafe.


## Features
* **Responsive Navigation:** A header that allows users to navigate between the Home, Menu, About, and Contact sections easily.
* **Theme:** A visually appealing landing area that sets the brand's tone using high-quality imagery.
* **Digital Menu:** A clean grid layout showcasing signature items like the Banana Latte and Banana Bread with prices.
* **Contact Integration:** A dedicated section for customer inquiries and project credits.
